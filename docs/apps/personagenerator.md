# 人设生成器

从聊天记录或文件生成通讯录、备忘录和记忆中心。

## 功能

- 导入聊天记录或文件
- 自动提取人设信息
- 一键生成通讯录角色、备忘录与记忆记录

## 使用方式

1. 打开「人设生成器」。
2. 上传聊天记录或相关文件。
3. 确认生成结果并导入到对应应用。
