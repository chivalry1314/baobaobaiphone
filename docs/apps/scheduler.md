# 定时任务

系统应用 · 配置系统自动任务，控制扫描频率与执行状态。

## 功能

- 查看系统已注册任务
- 配置任务扫描频率
- 启用/禁用任务
- 查看执行日志

## 使用方式

1. 打开「定时任务」。
2. 查看任务列表与当前状态。
3. 调整频率或开关任务。
