# 微信

即时通讯应用，可进行聊天、通讯录管理、朋友圈与个人资料操作。

## 功能

- 单聊与会话管理
- 通讯录角色关联
- 每日剧本消息自动发送
- 记忆中心同步

## 使用方式

1. 在桌面点击「微信」图标进入应用。
2. 选择或创建会话。
3. 发送消息，系统会根据当前角色上下文调用 AI 回复。
