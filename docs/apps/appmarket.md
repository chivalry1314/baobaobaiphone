# 应用市场

系统应用 · 线上/离线应用安装与开发者上传平台。

## 功能

- 浏览在线应用列表
- 安装/卸载运行时 HTML 应用
- 上传本地 HTML 文件作为离线应用
- 查看已安装应用快照

## 使用方式

1. 打开「应用市场」。
2. 选择在线应用点击安装，或切换到上传模式导入 HTML。
3. 安装后的应用会出现在桌面，点击即可运行。
