## 关于本项目

BaobaobaiPhone 是一个基于 **React + Vite + TypeScript** 的移动端桌面式 Web 应用容器。

本手册面向两类读者：

- **使用者**：了解项目功能、各应用用途与基本操作流程。
- **开发者**：掌握项目架构、开发规范、应用注册方式与部署流程。

如需编辑或补充内容，可直接修改 `docs/` 目录下的 Markdown 文件，推送后会自动部署。
